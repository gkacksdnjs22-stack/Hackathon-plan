내 여행에 맞게 다듬는 노트

이용 안내

추천은 출발점일 뿐이에요. 장소·시간·이동을 직접 편집하며 나만의 계획서를 만들어 보세요. 자주 묻는 질문 바로가기

1. 여행 노트 만들기

여행지, 시작일, 기간을 정하고 ‘추천으로 시작하기’를 누르세요. 관광지의 운영시간·휴무·예약·요금·날씨는 자동 반영되지 않으니 방문 전에 확인해 주세요.

2. 미정인 이동시간 확인하기

날짜별 출발지와 구간별 이동수단을 선택하세요. 아직 입력하지 않은 이동시간은 ‘미정’이며, 0분이 걸린다는 뜻이 아니에요. 미정인 구간이 있으면 이후 시각도 임시 계획이에요.

일정 수정에서 이동시간을 입력하거나 제공되는 차량 경로 조회 결과를 확인해 적용하세요. 이동수단이나 관광지를 바꾸면 관련 이동시간을 다시 정해야 해요. 직선거리 추천은 실제 도로·보행 경로가 아니에요. API 설정이나 제공기관 문제로 조회가 안 되면 표시되는 카카오맵 링크로 경로를 확인하고, 일정 시간은 직접 입력할 수 있어요.

3. 식사와 식당 선택하기

식사 카드의 ‘식당 직접 입력’에서 이름과 선택 사항인 주소·메모를 적어 저장하세요. 추천 목록을 조회하지 않아도 사용할 수 있고, 다시 열어 수정하거나 식당 정보를 지울 수 있어요. 추천 식당을 선택하면 식당 이름이 바뀝니다. 식사 시간은 그대로 유지되며 오가는 이동시간은 직접 추가해 주세요.

식사 이름은 배치된 시각에 따라 표시되며, 실제 식당 영업시간이나 예약 가능 여부를 보장하지 않아요. 식당을 담으면 이름과 주소만 반영돼요. 식당까지 오가는 이동시간은 자동으로 추가되지 않으므로 ‘일정 추가’에서 이동을 넣고 순서를 조정해 주세요.

4. 일정 수정하기

체류시간·이동시간·메모를 수정하면 뒤 일정의 시각도 바뀌어요. 타임라인 점의 순서 버튼으로 이동하고, 필요 없는 일정은 빼거나 다시 담을 수 있어요. ‘인쇄·PDF’에서 인쇄 창을 열어 PDF로 보관할 수 있어요.

노트 위의 ‘되돌리기’와 ‘다시 실행’으로 이 탭에서 수정한 내용을 최대 20단계 복구할 수 있어요. 새로고침하거나 다른 노트를 불러오거나 계정을 바꾸면 편집 기록은 비워져요.

5. 저장과 계정

브라우저 임시 저장과 계정 저장은 달라요. 계정 저장은 해당 서버에 계정 기능이 설정된 경우에만 사용할 수 있어요. 화면에서 기능을 사용할 수 없다고 안내하면 로그인이나 다른 기기에서 불러오기를 이용할 수 없어요.

브라우저 저장에 실패했다는 안내가 나오면 저장된 것으로 간주하지 마세요. 중요한 계획은 인쇄·PDF로 별도 보관해 주세요.

자주 묻는 질문

Q. 여행 계획은 어디에 저장되나요?

편집 중인 노트는 현재 브라우저에 임시 저장돼요. 계정에 보관하려면 로그인한 뒤 ‘계획표 저장’을 눌러 주세요. 이후 수정한 내용도 계정에 남기려면 ‘변경사항 저장’을 눌러야 해요. 브라우저의 사이트 데이터를 지우면 임시 저장본이 사라질 수 있어요.

Q. 다른 기기에서도 이어서 볼 수 있나요?

계정 기능을 사용할 수 있는 같은 사이트에서 같은 계정으로 로그인한 뒤, 시작 화면의 ‘저장한 계획’에서 열어 주세요. 브라우저 임시 저장만 한 노트는 다른 기기로 전달되지 않아요. 기기를 바꾸기 전에 계정 저장을 완료했는지 확인해 주세요.

Q. 이동시간 ‘미정’은 무슨 뜻인가요?

이동시간이 아직 입력되지 않았다는 뜻이에요. 실제로 이동에 0분이 걸린다는 의미가 아니며, 뒤 일정의 시각도 임시 계획이에요. 경로를 확인한 뒤 이동시간을 입력하거나, 차량 예상시간 조회 결과를 확인하고 ‘일정에 적용’을 눌러 주세요.

Q. 관광지나 교통편 조회가 안 돼요.

인터넷 연결과 화면의 오류 안내를 확인하고 잠시 후 다시 시도해 주세요. 교통편은 조회 날짜와 구간에 따라 결과가 없을 수 있으며, 시외버스는 당일 시간표만 조회할 수 있어요. 인증키나 API 설정 관련 안내가 계속되면 사이트 운영자에게 문의해 주세요.

Q. 저장이나 불러오기에 실패하면 어떻게 하나요?

저장 실패 안내가 나오면 저장 완료로 생각하지 말고 브라우저 저장 공간·설정이나 로그인 상태를 확인해 주세요. 불러오기 실패 시에는 저장본을 지우지 말고 오류 안내를 확인한 뒤 다시 시도해 주세요. 관광정보 조회 실패나 삭제된 장소 때문에 복원이 안 될 수도 있어요. 현재 화면에 계획이 보인다면 ‘인쇄 · PDF’로 별도 보관해 주세요.

Q. 저장한 계획이 많으면 어떻게 찾나요?

로그인 후 ‘저장한 계획’의 ‘계획 검색’에 계획 이름이나 여행 지역을 입력하세요. ‘부산 가족’처럼 띄어 쓰면 두 단어를 모두 포함하는 계획을 보여줘요. 검색한 상태에서 정렬하거나 계획을 불러오고 삭제할 수 있어요. ‘검색 지우기’를 누르면 전체 목록으로 돌아가요.

Q. 아직 정하지 않은 이동 구간을 한 번에 볼 수 있나요?

여행 노트의 ‘미정 이동 모아보기’를 펼치면 전체 날짜의 미정 구간이 나와요. 항목을 누르면 해당 날짜를 펼치고 출발지·도착지 또는 이동시간 입력 위치로 이동해요. 입력 후 저장하면 목록에 바로 반영돼요. 경로를 조회만 한 예상시간은 저장된 이동시간이 아니므로 목록에 남아 있어요.

Q. 일정 텍스트나 캘린더 파일로 내보낼 수 있나요?

여행 노트의 ‘일정 내보내기’에서 현재 날짜 또는 전체 여행을 고르세요. ‘일정 텍스트 복사’는 주소와 메모를 함께 복사하고, 복사가 차단되면 직접 복사할 텍스트 상자를 보여줘요. 편집 중인 내용은 먼저 저장해 주세요.

‘캘린더 파일 (.ics)’을 누르면 파일이 내려받아져요. 캘린더 앱의 가져오기 메뉴에서 이 파일을 선택해 주세요. 한국 시간과 자정 이후 시각을 반영하며, 미정 구간이 있는 날짜는 임시 시각으로 표시해요. 이후 변경은 자동 동기화되지 않고 반복해서 가져오면 중복될 수 있어요.

Q. 여행 계획을 PDF로 저장할 수 있나요?

여행 노트 위쪽의 ‘인쇄 · PDF’를 누르면 브라우저 인쇄 창이 열려요. 대상이나 프린터에서 ‘PDF로 저장’ 등 PDF 출력 항목을 선택하고 저장해 주세요. 항목 이름은 브라우저와 기기에 따라 다를 수 있어요. PDF는 보관·공유용이며 앱에 다시 불러와 편집하는 기능은 제공하지 않아요.
