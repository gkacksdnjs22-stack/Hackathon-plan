자동차 경로 · 예상 이동시간

카카오모빌리티 자동차 길찾기

출발지 또는 관광지 사이의 이동수단을 차량으로 선택하면 자동차 예상 이동시간·거리를 확인합니다. ‘일정에 적용’을 누르면 이동시간과 뒤 일정을 조정하고 저장합니다.

조회 시점의 교통을 기준으로 한 추천 경로 요약입니다. 미래 여행일의 교통 예측이 아니며, 대기·주차·휴게시간은 직접 더해 주세요. 조회만으로 일정은 바뀌지 않고, 적용한 시간도 직접 수정할 수 있습니다.

대중교통 경로 · 시간 · 환승

카카오맵 대중교통 경로 조회

선택한 두 지점 사이에서 버스·지하철을 포함한 실제 경로의 예상시간, 거리, 환승 횟수와 노선 요약을 조회합니다. 혼합 경로는 따로 표시합니다.

선택한 경로의 시간으로 현재 타임라인을 미리 보여줍니다. 조회를 닫으면 원래 시간으로 돌아오며, 저장·인쇄에는 직접 입력한 일정 시간을 사용합니다. 미래 여행일의 배차·지연 예측이 아니며, 제공 정책에 따라 응답을 저장·캐시하거나 일정에 자동 저장하지 않습니다.

방문 장소 · 배경 지도

방문 장소 지도

관광지 이름·주소·좌표는 한국관광공사 TourAPI 정보를 사용합니다. 배경 지도는 © OpenStreetMap contributors이며, 타일 이용 정책을 따릅니다. 지도를 펼칠 때 브라우저가 OpenStreetMap에 배경 타일을 요청합니다.

지도 표시에는 Leaflet 1.9.4를 사용합니다. BSD-2-Clause 라이선스의 배포 파일을 수정 없이 포함했으며 라이선스 전문을 제공합니다. 위치 표시는 여행 계획을 위한 것이며 실제 도로·도보 경로를 계산하지 않습니다.

떠나기 전, 잠깐만

여행 계획용 예상시간

앱의 체류·이동 추천시간과 직접 입력한 시간은 계획용 예상값이에요. 실제 교통편의 지연·결항에 따라 도착시각이 달라질 수 있어요.

가까운 정도는 직선거리로

장소를 묶거나 주변 맛집을 찾을 때의 거리는 좌표로 계산한 직선거리예요. 실제 도로·도보 경로와 이동시간은 달라질 수 있어요.

내부 이동수단 추천

관광지 사이 직선거리800m 이내는 도보를, 그보다 먼 구간은 대중교통·차량을 고려하도록 안내해요. 버스·지하철을 고르면 실제 대중교통 예상시간을 조회할 수 있고, 일정 시간은 직접 수정합니다. 도보 추천은 실제 보행 경로가 아닙니다.

운영정보는 방문 전 확인

관광지·음식점의 운영시간, 휴무, 예약과 교통편의 실제 운행 여부는 방문 전에 각 시설과 운행기관에서 확인해 주세요.
