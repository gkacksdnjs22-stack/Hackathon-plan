# 실제 브라우저 시나리오

Node.js 24 이상에서 프로젝트 폴더 기준으로 실행합니다.

```sh
npm ci
npm run test:e2e:install
npm run test:e2e
```

일반 단위·통합 검증은 기존 `npm test`로 실행합니다. 브라우저 검증은
`e2e/*.spec.mjs`를 Playwright로 별도 실행하며, `node --test`에 중복 포함되지 않습니다.

실제 Chromium의 독립 프로필과 전용 서버 `http://localhost:4179`를 사용합니다.
4179 포트가 사용 중이면 실행을 중단하며 기존 개발 서버를 재사용하지 않습니다.
테스트 서버는 메모리 SQLite와 합성 관광지·출발지를 사용하고 `.env`, 사용자
데이터베이스, 사용자의 브라우저 프로필을 열지 않습니다.

소셜 로그인은 실제 앱의 OAuth 시작·일회용 state·콜백·세션 코드를 통과합니다.
테스트가 로컬 시작 응답의 이동 주소를 로컬 콜백으로 교체하고, 서버의 제공자
HTTP 응답만 합성하기 때문에 외부 계정이나 API를 사용하지 않습니다.
실제 Google·Kakao·NAVER 계정의 동의 화면이나 제공자 설정을 검증하는 테스트는 아닙니다.

검증 범위:

- 추천 생성, 메모·체류시간 수정, 새로고침·새 탭에서 기기 초안 복원
- DAY 상단·하단 책갈피 이동, 선택 표시, 날짜별 내용 분리
- 네 도구의 제목·기능 버튼 준비, 선택 도구 스크립트 누락 시 빈 세부정보 숨김과
  기본 노트 편집·복원 유지
- 간결한 도구 모음에서 그룹별 팝업 열기, Escape 닫기·포커스 복원,
  DAY 이동 시 팝업 닫기, 모바일 두 줄 이내 배치와 가로 넘침 없음
- 합성 소셜 로그인, 계정 저장, 기기 초안 없는 새 세션에서 저장 문서 복원
- 소셜 로그인 전용 화면, 사용 종료된 아이디·비밀번호 API 차단,
  두 합성 계정 사이의 저장 목록·작성 중 노트 분리
- 공유 미리보기의 기본 비공개 항목, 비로그인 열람, 공유 사본 고정,
  새 링크로 교체, 공유 해제, 메모의 HTML 문자 안전 표시
- 전용 임시 브라우저 프로필을 완전히 종료·재시작한 뒤 인터넷 없이 사본 열람,
  DAY별 내용과 마지막 저장 시점, 계정 전환 시 다른 계정 사본 숨김
- 선택한 문화 취향이 새 관광지 추천에 반영되고 재접속 후 선택 장소 유지
- 방향별 합성 차량 이동시간 비교, 예약 완료 일정 고정, 적용 전 확인,
  되돌리기·다시 실행, 식사·휴식의 순서 자리 유지, 저장 문서에서 조회 비용 제외
- 운영정보의 명시적 조회, 이용시간·주간 휴무 경고, 복잡한 조건의 확인 필요 안내,
  조회 도중 DAY 이동 시 이전 결과 폐기
- 실행 중 발생하는 JavaScript 오류 및 스크립트 누락

실패하면 `artifacts/browser-results`에 화면 캡처와 Playwright 추적 파일이 남습니다.
합성 데이터만 포함하며 해당 폴더는 Git 추적에서 제외됩니다.
오프라인 재시작 테스트의 브라우저 프로필은 운영체제 임시 폴더 아래에 별도
생성하며, 테스트 종료 후 경로를 확인하고 삭제합니다.
순서 비교·운영정보 도구의 PC·모바일 검토 화면은
`artifacts/feature-review-desktop.png`, `artifacts/feature-review-mobile.png`에 저장합니다.
팝업을 연 PC·모바일 화면은 `artifacts/feature-review-dialog-desktop.png`,
`artifacts/feature-review-dialog-mobile.png`에 저장합니다.
